# 잠든 스파크의 숲 (환경 시험용 프로토타입)

꼬마 마녀 루미가 숲에 숨어 버린 빛의 정령 "스파크"를 모아 잠든 큰나무를 깨우는 힐링 탐험 게임입니다.
"작은 생물을 찾아 모으고 → 모은 에너지로 길을 열고 → 새 능력으로 퍼즐을 푼다"는 원작의 플레이 구조만 가져오고,
캐릭터·맵·그림·글·소리는 전부 새로 만들었습니다 (원본 에셋은 포함되어 있지 않습니다).

## 실행 방법
1. Unity Hub에서 **2D 템플릿**(Built-in 2D 또는 Universal 2D)으로 새 프로젝트를 만듭니다. Unity 2021.3 LTS 이상 권장.
2. 이 폴더(`unity/`)의 `Assets/` 안 내용(`Resources`, `Scripts`)을 새 프로젝트의 `Assets/` 로 복사합니다.
3. `Assets/Resources/boot.json`의 `"game"`을 `"forest"`로 바꾸고, 아무 씬(기본 SampleScene)에서 **Play**. 씬 설정은 필요 없습니다. 게임이 실행 시점에 스스로 월드를 조립합니다.

* 패키지 의존성 없음: 타일맵·UI·URP 없이 SpriteRenderer + IMGUI 만 사용합니다.
* 입력: 구 Input Manager / 새 Input System 어느 쪽이든 동작합니다 (게임패드 지원).
* 이미지는 임포트 설정 영향을 받지 않도록 PNG 바이트(`*.bytes`)로 들어 있고 런타임에 Point 필터로 로드됩니다.

## 조작
| 동작 | 키 |
|---|---|
| 이동 | WASD / 방향키 |
| 흔들기 · 대화 · 읽기 | E (또는 Z, Enter) |
| 스파크 모으기 (지팡이 빛) | Space 꾹 누르기 |
| 앞장선 동료의 능력 | Q |
| 동료 교대 | Tab |
| 스파크 도감 / 도움말 | J / H |
| 다음 스테이지로 바꿔 보기 (미리보기용, 진행은 처음부터) | F2 |

## 핵심 시스템
* **스테이지마다 다른 색과 분위기**: 색은 코드에 고정돼 있지 않고 `data/stages/<id>.json` 테마에서 옵니다. 지금은 같은 숲 맵을
  봄 한낮(`spring_day`)·가을 해질녘(`autumn_dusk`)·달밤(`moon_night`) 세 가지로 구워 두었습니다. 항목 설명은 `design/stages.md`.
* **숲터(구역)마다 다른 디자인**: 오두막 빈터(봄빛 초록), 버섯 숲(어스름한 청록 + 거대 버섯), 연못 풀밭(물빛 민트),
  꽃바람 언덕(따뜻한 노랑 + 벚꽃·황금 나무), 큰나무 숲터(은빛 연두). 지면 색, 나무 팔레트, 소품, 사는 스파크 종류가 모두 다릅니다.
* **숲터에 어울리는 동료 수집**: 각 숲터의 정령은 그 숲터 스파크를 6마리 모아야 마음을 엽니다.
  버섯 숲 = 등불버섯 정령 포포(불빛), 연못 풀밭 = 물방울 정령 퐁이(꽃비), 꽃바람 언덕 = 바람새 후우(바람).
* **동료 교대 퍼즐**: 앞장선 동료의 능력만 쓸 수 있고 Tab으로 교대합니다.
  불빛 → 그늘 덩굴 제거·등불버섯 깨우기 / 꽃비 → 시든 꽃·새싹 다리 / 바람 → 낙엽 더미·나무 위 스파크.
  마지막 꽃등 세 송이는 바람(낙엽 걷기) → 꽃비(꽃 피우기) → 불빛(불 밝히기) 순서로 셋을 번갈아 써야 켜집니다.

## 진행
오두막 빈터 → (빛 10) 등불문 → 버섯 숲에서 포포 → 그늘 덩굴을 걷고 연못 풀밭에서 퐁이 → 새싹 다리 →
꽃바람 언덕에서 후우 → 낙엽을 날리고 (빛 45) 등불문 → 꽃등 3송이 + 빛 80으로 큰나무를 깨우면 엔딩.
숲 전체에 빛 162 분량이 숨어 있고, 새 동료를 얻은 뒤 지나온 숲터로 돌아가면 더 찾을 수 있습니다.

## 아트 규칙
* 16px 타일 기준 탑다운 3/4 뷰, 맵 60×44 타일 (960×704px).
* **색상 매칭 선택적 외곽선**: 외곽선은 맞닿은 면 색을 한 단계 짙게(보랏빛으로 살짝 기울여) 만든 색이며,
  빛을 받는 위/왼쪽은 더 옅게 들어갑니다. 검정·단일 암갈색 외곽선은 쓰지 않습니다.
* 파스텔 3~4톤 램프. 빛 얼룩·빛기둥·떠다니는 가루의 색과 세기는 스테이지 테마가 정합니다 (봄 한낮은 따뜻한 햇살, 달밤은 달빛과 반딧불).
* 팔레트를 바꿔도 외곽선은 맞닿은 면 색에서 계산되므로 규칙이 그대로 지켜집니다.

## 폴더
* `Assets/Scripts/SparkForest/` — C# 12개 파일 (Game, Stage, Player, Spark, Thing, Ambient, Hud, Fx, Sfx, Art, In, Texts)
* `Assets/Resources/SparkForest/stages/<id>/` — 스테이지별 아틀라스·지면 그림·맵·분위기 (구운 결과, 손으로 고치지 않음)
* `ArtSource/` — 확인용 PNG(`preview/`)와 생성 스크립트(`tools/`). 테마나 스프라이트를 고친 뒤 저장소 루트에서
  `python3 unity/ArtSource/tools/bake_all.py` (numpy, Pillow 필요) 를 돌리면 모든 스테이지가 다시 구워집니다.
* 대사·이름은 `Texts.cs`, 필요 수치·배치는 `gen_map.py`, 능력에 반응하는 규칙은 `Thing.cs`의 `OnAbility`.
* 새 동료/능력 추가: `sprites.py`에 `comp_<id>`·`ui_<id>` 스프라이트 → `gen_map.py`에 `add('comp', ...)` → `Game.UseAbility`와 `Thing.OnAbility`에 분기 추가.
