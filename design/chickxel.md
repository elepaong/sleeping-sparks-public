# Chickxel 사용설명서

도트(픽셀 아트) 스프라이트를 그리고 정리하는 데스크톱 앱 **Chickxel**의 사용법입니다. 어느 세션이 읽어도 같은 내용을 보도록 정리했습니다.

- 출처: https://chickxel.com/guide (2026-11-08 확인)
- 확인 방법: 가이드 전체를 구간별 요약으로 읽었습니다(원문을 직접 연 것은 아님). 직접 써서 확인한 항목은 아직 없습니다. 확인하면 맨 아래 "확인 기록"에 적습니다.
- 원래 Unity 2D용 무료 도트 편집기이지만 출력이 PNG 스프라이트 시트라서 Godot에서도 쓸 수 있습니다. Unity 전용 산출물(`.meta`, `.spriteLib`)은 이 프로젝트에서 쓰지 않습니다.

## 세션이 먼저 알아야 할 것

1. Chickxel은 사람이 Mac에서 켜는 GUI 앱입니다. 클라우드·채팅 세션은 앱을 열거나 아래 MCP 도구를 직접 부를 수 없습니다.
2. MCP 서버는 앱의 AI 채팅을 쓸 때만 이 컴퓨터 안(`127.0.0.1`)에 임시로 열리고, 앱을 켤 때마다 바뀌는 토큰으로 접근을 막습니다. 앱이 띄운 Claude Code/Codex CLI에만 연결 정보를 넘기므로, 다른 세션에서 접속하거나 사용자 MCP 설정에 등록하는 방법은 없습니다.
3. 그래서 세션이 맡는 일은 다음과 같습니다. 앱 조작과 결과 선별은 사람이 합니다.
   - 앱의 AI 채팅에 붙여넣을 프롬프트 작성
   - 에셋 규격 점검 (`CLAUDE.md`의 에셋 규격표 기준)
   - 내보낸 PNG 검수와 Godot 연결
   - `design/art-direction.md`, `design/progress.md` 기록
4. 컴퓨터 사용(화면 조작) 기능으로 앱을 직접 다루는 방법은 이 문서에서 다루지 않습니다. 시험한 적이 없습니다.

## 준비 상태 (사람이 확인)

- 설치 위치(macOS): `/Applications/Chickxel.app`. 설치 방법은 가이드를 봅니다. 설치 명령은 이 문서에 옮기지 않았습니다.
- AI 채팅에는 Claude Code 또는 Codex CLI가 Mac에 따로 설치돼 있어야 합니다. 앱 설치 파일에 들어 있지 않습니다.
- 처음 AI 채팅을 열면 "AI 상태 및 설정" 창이 설치·로그인·편집기 연결을 점검합니다. 이 점검은 모델에 요청을 보내지 않습니다.
- AI 사용량은 CLI 구독에서 차감되고 API 키는 필요 없습니다.
- 설정 폴더: `~/Library/Application Support/Chickxel/`

| 항목 | 내용 |
|---|---|
| `settings.json` | 환경 설정 |
| `export-presets.json` | 내보내기 프리셋 |
| `History/`, `Trash/` | 실행취소 기록(기본 30일, 500MB), 휴지통 |
| `Logs/` | 오류 로그 `crash-날짜-시각.log`, 최근 20개 |
| `Recovery/` | 앱이 비정상 종료될 때 저장하지 않은 문서 복구본. 다음 실행 때 자동으로 열리지 않음 |
| `References/` | AI 참고 자료 |

## AI 채팅

- 열기: `Ctrl`+`L` 또는 메뉴 AI > AI 채팅. 보내기는 `Enter`, 줄바꿈은 `Shift`+`Enter`.
- 그림은 이미지 첨부·붙여넣기·끌어 놓기로 넣습니다.
- 답을 받는 중에 보낸 메시지는 대기 줄에 들어갑니다.
- AI의 답 하나는 실행취소 한 단계입니다. 답 아래 "이 단계 되돌리기" 또는 `Ctrl`+`Z`로 되돌립니다.
- 잠긴 레이어는 AI가 건드리지 않습니다. "지금 그림만 고치게 하기"를 켜면 열린 그림 하나만 고칩니다.
- AI는 셸 명령과 웹 검색이 꺼진 채 Chickxel 도구만 씁니다.
- 지난 대화는 AI마다 20개까지 남고, 즐겨찾기한 대화는 자동 삭제되지 않습니다.

## AI 그림을 도트로 정리

AI가 만든 "도트 느낌" 그림을 원본의 한 칸이 결과 픽셀 하나가 되도록 정리하는 기능입니다. 지금 가장 막힌 도트 변환 문제와 가장 가까운 기능입니다.

- 입력: 끌어 놓기, `Ctrl`+`V`, 파일 찾기. PNG·JPG·BMP·GIF·WebP를 열 수 있습니다. 움직이는 그림은 프레임을 격자로 이어서 원본으로 씁니다.
- 한계: 프레임 300개, 격자 가로·세로 최대 64칸.
- 흐름: 원본 넣기 → 후보 비교 → 더 나은 설정 찾기 → 색 다듬기 → 넣기.
- 정리 단계: 배경 지우기, 프레임 나누기, 픽셀 격자, 칸 색, 팔레트, 정리, 점수(0~100점).
- 기본 프리셋 9종: 기본, 같은 색상 계열, 작은 스프라이트(32px), 색 적게(16색), 원본 색 유지, OKLab, 빠른 확인, 원본 충실, 깔끔한 도트. 제한 시간은 300초이고 빠른 확인만 30초입니다.
- 주의: 가이드는 입력을 "픽셀 느낌 그림"으로 전제합니다. 이 프로젝트의 ChatGPT 시안은 파스텔 수채풍이라 같은 방식으로 되는지는 시험해야 압니다.

## 내보내기 (Godot 기준 제안)

`Ctrl`+`E`로 내보내기 창을 엽니다. 저장(`Ctrl`+`S`)할 때 함께 내보내는 "저장 시 내보내기"는 새 프로젝트에서 기본으로 켜져 있습니다.

| 설정 | 가이드의 기본값 | Godot용 제안 |
|---|---|---|
| 배치 | 격자 또는 자동 | 격자 |
| 칸 사이 간격 | 1px (0~64) | 0 (바꾸지 않을 거면 Godot 쪽 `separation`을 1로 맞춤) |
| 배율 | 1~16배 | 1 (확대는 엔진에서) |
| 파일 형식 | PNG, JPG, TGA, BMP | PNG |
| 파일 나누기 | 태그·부위·스킨별 | 태그별 (`lumi_idle`, `lumi_active` 식) |
| Unity `.meta` | 끔·자동·항상 (자동은 Unity `Assets` 안일 때만 씀) | 끔 |
| `.spriteLib` | 그룹·스킨마다 생성 | 불필요 |

칸 이름은 프레임 번호(0부터) 또는 태그 기준으로 붙습니다. GIF 내보내기(배율 1~10배)는 공유·검토용으로 씁니다.

## 파일과 저장

- 프로젝트 파일 `.chickxel`은 ZIP입니다. `project.json`과 칸별 PNG가 들어 있고 형식 버전은 5입니다. 예전 Chickxel에서는 열 수 없고, 더 새 버전의 파일은 열지 않고 알려줍니다.
- 자동 저장: 편집이 3초 없으면 저장합니다. 디스크에 `.chickxel`이 있는 파일만 해당합니다.
- 스크립트 효과의 원문도 `.chickxel`에 함께 저장되어 다른 컴퓨터에서도 같은 모습으로 그려집니다.
- git에서는 `.chickxel`이 바이너리라 diff가 안 됩니다. 내보낸 PNG와 같은 이름으로 같은 폴더에 두는 것을 제안합니다(아직 미확정).

## 한계와 주의

- 갤러리 업로드와 에셋 공유는 계정 로그인이 필요합니다. 그리기와 저장에는 필요 없습니다.
- 팔레트 웹, 업데이트 확인, AI 연결, 갤러리는 인터넷이 필요합니다.
- 팔레트 저작권은 각 작성자에게 있습니다.
- 앱 라이선스는 "소스 공개 라이선스"입니다. README 기준으로 공식 배포판은 상업 작업에도 무료이고 만든 그림은 만든 사람 것입니다 (2026-11-10 확인, [`licenses.md`](licenses.md)). LICENSE 전문은 아직 읽지 못했습니다.
- AI 그림 생성의 상업 이용 조건은 사용하는 제공자(Codex/ChatGPT 등) 약관을 따르므로 Steam 출시 전에 확인합니다. 무료 Scenario 결과물은 레퍼런스 전용이라는 `CLAUDE.md` 규칙은 그대로 적용됩니다.
- macOS에서 "확인되지 않은 개발자" 경고가 뜨면 앱을 우클릭 → 열기, 안 되면 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누릅니다.
- 오류가 나도 앱은 대부분 계속 쓸 수 있습니다. 로그는 도움말 메뉴의 오류 로그 폴더에서 열고, 제보할 때는 버전과 재현 순서를 적습니다.

## 이 프로젝트에 적용 (제안, 미확정)

`CLAUDE.md`의 에셋 규격표를 Chickxel 작업으로 옮긴 것입니다. 확정되면 `CLAUDE.md`로 올립니다.

| 에셋 | 규격 | Chickxel 작업 방법 |
|---|---|---|
| 스파크 (필드) | 24×24, 대기 4 + 발동 6프레임 | 캔버스 24×24, 태그 `idle`(1~4), `active`(5~10) |
| 필드 캐릭터 | 48×72 (2026-11-11부터. 아래 루카 프롬프트의 32×48·128×384는 옛 규격 — 숫자를 48×72·192×576으로 바꿔 쓴다), 8방향 × 걷기 4프레임 | 캔버스 48×72, 방향별 태그 8개(`walk_down`, `walk_down_right`, `walk_right`, `walk_up_right`, `walk_up`, `walk_up_left`, `walk_left`, `walk_down_left`). 오른쪽 계열 3방향을 그려 왼쪽 계열을 좌우 반전해도 됨(소품 비대칭이 없을 때) |
| 타일 | 32×32 | 캔버스 32×32. 타일 이음새 확인 도구는 가이드에 없음 |
| 도감 카드, 초상화, 퍼즐 그림, 양피지 삽화 | 512 / 1200×800 / 800×600 | 해당 없음. 일러스트 경로(ChatGPT, Draw Things, ComfyUI)를 그대로 씀 |

작업 순서 제안(스파크 1종 기준):
1. `design/art-direction.md`에서 확정한 시안을 고른다.
2. Chickxel에서 24×24 새 프로젝트를 만들고, AI 채팅에 시안을 첨부하거나 "AI 그림 도트로 정리"에 원본을 넣는다.
3. 팔레트를 정리하고 태그를 나눈다. 필요하면 외곽선·빛 효과를 얹는다.
4. 위 표대로 내보내고, 산출물을 `assets/sparks/` 등에 두고, Godot에서 확인한다.
5. 에셋 이름·사용한 설정·프롬프트를 `design/art-direction.md`에 기록한다.

앱의 AI 채팅에 붙여넣을 프롬프트 예시 (시험 전):

```
첨부한 그림을 24×24 도트 스프라이트로 바꿔줘. 몸의 윤곽은 유지하고 색은 16색 이내로 줄여줘. 배경은 투명으로.
```
```
지금 그림에 대기 모션 4프레임을 만들어줘. 몸이 위아래로 1픽셀씩 움직이게 하고, 프레임 1~4에 `idle` 태그를 붙여줘.
```
```
현재 팔레트를 유지한 채 외곽선 효과를 추가해줘. 효과는 영구 적용하지 말고 레이어 효과로 남겨줘.

```

- 팔레트에 부분별 윤곽 색을 포함해서 색 개수를 알려줘 (윤곽 색 때문에 2~4색 늘어나도 괜찮아).
